The data behind the analyses

Every analysis here comes from the same mirror of public data (1,734 tables, 286 datasets, 130 sources, 545 GB), open for querying at db.rodado.xyz: a read-only SQL terminal in the browser, over the same data each analysis used. To research with an agent (LLM, script, notebook), the guide at /llm lays out the HTTP path, from topic to query. Queries saved by people using the terminal are listed at /index, each one a short link that opens already running.
