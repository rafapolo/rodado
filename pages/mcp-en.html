rodado Data Catalog · Brazil

Brazilian public-data catalog, served as an MCP server

A thematic index over 1,403 Brazilian public tables — RAIS, SIM, TSE, CGU, IBGE, INEP and more — queryable directly with DuckDB. Each card below is a research theme; each row inside it is a table you can query.

The catalog includes a growing set of independently-collected sources — international sanctions lists (EU, UN, OFAC, OpenSanctions), ICIJ Offshore Leaks, SICAF, SINAN Violência, Consumidor.gov.br, PGFN active debt and state Courts of Accounts — see the full catalog of these sources.

Connect your agent

In a terminal:

claude mcp add --transport http rodado https://db.rodado.xyz/mcp

Settings → Connectors → Add custom connector, and paste the URL:

https://db.rodado.xyz/mcp

In ~/.cursor/mcp.json:

{"mcpServers": {"rodado": {"url": "https://db.rodado.xyz/mcp"}}}

In a terminal:

code --add-mcp '{"name":"rodado","type":"http","url":"https://db.rodado.xyz/mcp"}'

In a clone, with uv:

git clone --depth 1 https://github.com/rafapolo/rodado && cd rodado
claude mcp add rodado -- uv run "$PWD/mcp/mcp_server.py"

Hosted and public: nothing to install, no SSH, no local data. Credential required from 2026-10-27 — see mcp/MCP.md.

The server's tools

Seventeen MCP tools expose the catalog, the semantic layer (joins, metrics, hierarchies) and the DuckDB mirror. By default every query goes to the public db.rodado.xyz API: the measured pitfalls of the tables and columns it touches come back in avisos, and a query that cites a column of a pitfall that yields a wrong answer without an error is refused, with the explanation, until it is repeated with ciente=True.

  • list_datasets() — the catalog datasets, with table counts
  • list_tables(dataset) — tables of a dataset, with name suggestions
  • describe_table(table) — columns and types, preceded by the dataset's measured pitfalls
  • get_join_keys(column?) — documented join keys across datasets
  • resolve_join(a, b) — a ready ON clause between two tables, with key normalization
  • explain_column(column) — why a common column (valor, sexo) does not join or decode across datasets
  • get_metric(name) · list_metrics() — named calculations (population, GDP per capita, CAGED net jobs)
  • rollup(level, level_above) — SQL expression that aggregates CNAE, ICD-10 or municipality to a higher level (subclass → division, municipality → state)
  • run_sql(sql, ciente?) — read-only SQL (SELECT/WITH), with measured pitfalls in avisos
  • consultar_cnpj(cnpj) — company, establishments and partners from the Federal Revenue registry
  • consultar_divida_ativa · consultar_precos_combustivel · consultar_jurisprudencia_stj · consultar_populacao_carceraria — SQL-free shortcuts over PGFN, ANP, STJ and SISDEPEN
  • consultar_cep(cep) · consultar_painelprecos(code) — live, on ViaCEP and ComprasGov's price panel
