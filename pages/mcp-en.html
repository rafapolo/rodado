rodado Data Catalog · Brazil

Brazilian public-data catalog, served as an MCP server

A thematic index over 839 Brazilian public tables — RAIS, SIM, TSE, CGU, IBGE, INEP and more — queryable directly with DuckDB. Each card below is a research theme; each row inside it is a table you can query.

The catalog includes a growing set of independently-collected sources — international sanctions lists (EU, UN, OFAC, OpenSanctions), ICIJ Offshore Leaks, SICAF, SINAN Violência, Consumidor.gov.br, PGFN active debt and state Courts of Accounts — see the full catalog of these sources.

The server's tools

Eight MCP tools expose the catalog and the DuckDB mirror. Catalog table names work directly in SQL: when a table has no view in the database, the query is automatically rewritten against the local Parquet files.

  • list_datasets() — all 204 datasets with table counts
  • list_tables(dataset) — a dataset's tables, with name suggestions
  • describe_table(table) — columns, types, descriptions and Parquet path
  • search_tables(query) — semantic search over the 778 tables
  • get_join_keys(column?) — documented join keys across datasets
  • run_sql(sql) — read-only SQL (SELECT/WITH) on the DuckDB mirror
  • consultar_cnpj(cnpj) — company, branches and partners from the full registry
  • consultar_cep(cep) — address lookup via ViaCEP
Connect (Claude Desktop / Claude Code)
{
  "mcpServers": {
    "rodado": {
      "command": "python3",
      "args": ["/path/to/rodado/mcp_server.py"]
    }
  }
}

Requires SSH access to the data mirror — restricted to selected members. The schema catalog and join keys are public in the repository.
