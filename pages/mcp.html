rodado Catálogo de Dados · Brasil

Catálogo de dados públicos brasileiros, exposto como servidor MCP

Um índice temático sobre 778 tabelas públicas brasileiras — RAIS, SIM, TSE, CGU, IBGE, INEP e outras — consultáveis diretamente com DuckDB. Cada card abaixo é um tema de pesquisa; cada linha dentro dele é uma tabela consultável.

O catálogo inclui um conjunto crescente de fontes coletadas independentemente — sanções internacionais (UE, ONU, OFAC, OpenSanctions), ICIJ Offshore Leaks, SICAF, SINAN Violência, Consumidor.gov.br, dívida ativa da PGFN e Tribunais de Contas estaduais — ver o catálogo completo dessas fontes.

As ferramentas do servidor

Oito ferramentas MCP expõem o catálogo e o espelho DuckDB. Nomes de tabela do catálogo funcionam direto no SQL: quando não há view no banco, a consulta é reescrita automaticamente para os arquivos Parquet locais.

  • list_datasets() — os 187 datasets com contagem de tabelas
  • list_tables(dataset) — tabelas de um dataset, com sugestões de nome
  • describe_table(tabela) — colunas, tipos, descrições e caminho Parquet
  • search_tables(consulta) — busca semântica em português sobre as 778 tabelas
  • get_join_keys(coluna?) — chaves de junção documentadas entre datasets
  • run_sql(sql) — SQL somente-leitura (SELECT/WITH) no espelho DuckDB
  • consultar_cnpj(cnpj) — empresa, estabelecimentos e sócios pela base da Receita
  • consultar_cep(cep) — endereço via ViaCEP

  "mcpServers": {
