Os dados por trás das análises

Todas as análises daqui saem do mesmo espelho de dados públicos (1.752 tabelas, 294 datasets, 130 fontes, 545 GB), aberto para consulta em db.rodado.xyz: um terminal SQL no navegador, só leitura, com o mesmo dado que cada análise usou. Para pesquisar com um agente (LLM, script, notebook), o guia em /llm mostra o caminho por HTTP, do tema à consulta. As consultas salvas por quem usa o terminal ficam em /index, cada uma num link curto que abre já rodando.
