Uma leitura sociológica do Brasil, em dados

Vínculos de emprego, óbitos, contratos públicos, resultados eleitorais, matrículas escolares — os registros que o próprio Estado brasileiro produz para administrar a população, cruzados por raça, classe, gênero e território.

Este projeto espelha 533 tabelas da Base dos Dados — RAIS, SIM, TSE, CGU, IBGE, INEP, CNES e outras fontes oficiais — e as lê a partir de uma pergunta sociológica, não de uma vitrine técnica: o que esses registros, cruzados, revelam sobre desigualdade e poder no Brasil? Não é pesquisa de opinião nem modelo teórico. É o retrato que o Estado já tem de si mesmo, através de dados administrativos que raramente são lidos lado a lado.

Cada um dos 34 temas abaixo combina uma narrativa investigativa com as tabelas de evidência por trás dela, para que qualquer afirmação possa ser conferida, não só lida. Os achados são apresentados de forma direta — no tom do jornalismo de dados, não da cautela acadêmica — mas toda tabela vem da fonte oficial citada, sem alteração de valores.

A cobertura de dados, a proveniência institucional e os detalhes técnicos de como a plataforma funciona estão descritos com mais profundidade no README do repositório e no apêndice técnico.

Sobre os dados

Os dados vêm da Base dos Dados, que mantém um espelho público de tabelas de instituições brasileiras no BigQuery. Este projeto reexporta 533 dessas tabelas (~675 GB em Parquet+zstd) e as consulta sob demanda via DuckDB, permitindo cruzar bases de ministérios, tribunais e institutos diferentes numa única consulta.
